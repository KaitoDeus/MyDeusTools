⚙️ Engineering & Architecture Deep-Dive

Built for Speed, Reliability, and Zero Bloat

Explore how modern .NET 8, C# 12, MVVM design patterns, low-level Win32 P/Invoke interop, and 173 automated unit tests create a rock-solid desktop application.

.NET

.NET 8.0 & C# 12 Modern Core

Leverages modern language features including primary constructors, required properties, collection expressions, pattern matching, and SIMD hardware acceleration.

ReadyToRun AOT • Single-File Compression
WPF

WPF-UI 3.0 & Mica Backdrop

Brings official Windows 11 Fluent 2 aesthetics into native WPF. Native Mica materials allow the user's desktop wallpaper to subtly tint the app window while keeping rendering butter-smooth at 144Hz+.

Mica Material • Dynamic Dark/Light Theme
MVVM

CommunityToolkit MVVM

Clean Model-View-ViewModel architecture utilizing source generators (`[ObservableProperty]`, `[RelayCommand]`). Completely decouples UI XAML from business logic.

Source Generators • Microsoft DI Container
Win32

Native Win32 Interop Layer

Direct `user32.dll` and `gdi32.dll` P/Invoke calls. Zero heavy middleware: operates at the native Windows kernel message level for instant execution and minimal overhead.

user32.dll • gdi32.dll • Zero Polling
173✓

173 Automated xUnit Tests

100% passing test suite with FluentAssertions and Moq. Verifies dependency injection registration, ViewModel reactive state flows, and bilingual dictionary key symmetry.

xUnit • FluentAssertions • Moq
100%

100% Offline Privacy Guarantee

Strictly no network sockets, analytics SDKs, Google Analytics, or background telemetries. Sticky notes and settings are persisted as clean JSON on local disk.

Zero Telemetry • Local JSON Storage
