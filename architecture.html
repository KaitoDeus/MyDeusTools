> Three-Tier Hybrid Design

React 19 TerminalUI Web + .NET 8 Loopback Win32 Agent + Native WPF Desktop (282 xUnit tests).

LAYER_01 // WEB_CLIENT

React 19 + Vite 8 + TerminalUI

13 lazy-loaded views, --tui-* Light/Dark tokens, CRT toggle & Tailwind v4.

LAYER_02 // LOOPBACK_AGENT

.NET 8 Local Companion Agent

Zero NuGet deps. Loopback-only HttpListener on 127.0.0.1:41950 + PNA headers.

LAYER_03 // WIN32_INTEROP

User32 & Mockable IMouseInterop

mouse_event, SetCursorPos, F6/F7 40ms edge hotkeys, HWND_TOPMOST & WS_EX_LAYERED.

LAYER_04 // STORAGE

Dexie IndexedDB & JSON Disk

MyDeusToolsWebDB (notes, snippets, colors) on Web; Data/*.json on WPF.

Compile-Time Symmetry

_viSymmetryCheck enforces TypeScript vi/en parity; 57 tests verify WPF XAML.

LAYER_06 // VERIFICATION

282 Automated xUnit Tests

100% pass rate across 20 classes (WPF Services/VMs + Agent OsAutoClickEngine).

> Hybrid Control Flow

[ Browser: MyDeusTools.Web ]
  |-- Client Tools (PDF/Img/JSON/Dexie) ---> RAM Only
  '-- OS Controls (Click / Power / TopMost)
        |  fetch('http://127.0.0.1:41950/api/...')
        v
[ Windows: MyDeusTools.Agent (.NET 8) ]
  |-- LocalHttpBridgeServer (Loopback ONLY)
  |-- GlobalHotkeyService (F6 Toggle, F7 Capture)
  |-- OsAutoClickEngine (mouse_event, >= 10ms)
  |-- OsSystemPowerService (shutdown /s /r /h /a)
  '-- OsWindowPinnerService (TopMost / Alpha)
