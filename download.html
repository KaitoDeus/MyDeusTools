Start the TerminalUI Web App, optional .NET 8 Local Companion Agent, or portable WPF EXE.

MyDeusTools.Web

Client-side React 19 + Vite 8 + IndexedDB.

$ npm --prefix MyDeusTools.Web install
$ npm run web:dev
02 // WIN32_AGENT

MyDeusTools.Agent

OS Shutdown, F6/F7 Auto-Click & Window Pinner (127.0.0.1:41950).

$ npm run agent:dev
$ npm run agent:publish

Portable single-file EXE (WPF-UI 3.0 + FFmpeg + PDFsharp).
