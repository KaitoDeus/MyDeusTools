Frequently Asked Questions

Everything you need to know about MyDeusTools.

Is MyDeusTools completely free and open-source?

Yes, 100%! MyDeusTools is licensed under the permissive MIT License. You can inspect the source code, build your own binaries, and use it freely for personal or commercial projects.

Does MyDeusTools collect any user data or telemetry?

Never. MyDeusTools is 100% offline. All settings, sticky notes, and color histories are saved strictly as local JSON files on your machine with zero external network tracking.

Do I need to install .NET 8 runtime to use the application?

No! When compiled with the self-contained publish flag, the application bundles the minimal runtime components directly inside the single .exe file. It runs out of the box on Windows 10 and 11 (64-bit).

How does Window Pinner and Opacity work?

It utilizes native Win32 APIs (SetWindowPos with HWND_TOPMOST and SetLayeredWindowAttributes with LWA_ALPHA). This allows any standard application window on Windows to float above all others with custom transparency.
