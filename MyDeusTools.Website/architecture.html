// ./ARCHITECTURE_SPECIFICATION

> Three-Tier Hybrid Architecture

Built on a clean separation between a client-side React 19 TerminalUI Web app, a zero-dependency .NET 8 loopback Win32 Companion Agent, and the native WPF Desktop edition — verified by 282 unit tests.

LAYER_01 // WEB_CLIENT

React 19 + Vite 8 + TerminalUI

Lazy-loaded 13-view shell styled via CSS semantic tokens (--tui-*), zero border-radius, JetBrains Mono, CRT scanline toggle, and Tailwind CSS v4.

LAYER_02 // LOOPBACK_AGENT

.NET 8 Local Companion Agent

Zero external NuGet dependencies. Uses System.Net.HttpListener bound exclusively to 127.0.0.1:41950 with CORS + Access-Control-Allow-Private-Network.

LAYER_03 // WIN32_INTEROP

User32 & Mockable IMouseInterop

Abstracts mouse_event, SetCursorPos, GetAsyncKeyState (40ms F6/F7 edge hotkeys), EnumWindows, HWND_TOPMOST, and WS_EX_LAYERED opacity behind clean interfaces.

LAYER_04 // STORAGE

Dexie IndexedDB & JSON Disk

Browser state lives locally in MyDeusToolsWebDB (notes, snippets, colors) + localStorage preferences. Desktop WPF stores thread-safe JSON in Data/*.json.

LAYER_05 // I18N_SAFETY

Compile-Time Symmetry (_viSymmetryCheck)

Missing keys in translations.ts immediately fail TypeScript compilation during npm run web:build. WPF enforces symmetry across Strings.*.xaml via 57 xUnit tests.

LAYER_06 // VERIFICATION

282 Automated xUnit Tests

100% pass rate across 20 test classes using xUnit 2.9.2, Moq 4.20.72, and Xunit.StaFact — covering WPF MVVM/Services plus OsAutoClickEngine in Agent.

> Hybrid Data & Control Flow

[ Browser: MyDeusTools.Web ]
  |-- Client Tools (PDF, Img, JSON, Dexie) ---> Executed 100% in RAM
  '-- OS Controls (Click / Power / TopMost)
        |  fetch('http://127.0.0.1:41950/api/...')
        v
[ Windows: MyDeusTools.Agent (.NET 8) ]
  |-- LocalHttpBridgeServer (Loopback ONLY)
  |-- GlobalHotkeyService (F6 Toggle, F7 Capture)
  |-- OsAutoClickEngine (mouse_event, >= 10ms)
  |-- OsSystemPowerService (shutdown /s /r /h /a)
  '-- OsWindowPinnerService (HWND_TOPMOST / Alpha)
