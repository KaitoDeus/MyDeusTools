> Run Locally or Package Binaries

Choose how to run MyDeusTools: launch the TerminalUI Web App in seconds, connect the optional .NET 8 Local Companion Agent for Win32 OS features, or package/download the standalone WPF Desktop EXE.

OPTION_01 // WEB_APP (RECOMMENDED)

MyDeusTools.Web

Runs 100% locally in your browser using React 19 + Vite 8 + IndexedDB. Zero server uploads.

$ npm --prefix MyDeusTools.Web install
$ npm run web:dev
OPTION_02 // WIN32_AGENT (OPTIONAL)

MyDeusTools.Agent

Unlocks OS Shutdown/Restart/Hibernate tab, global F6/F7 Auto-Click, and desktop Window Pinner via http://127.0.0.1:41950/.

$ npm run agent:dev
$ npm run agent:publish
OPTION_03 // DESKTOP_WPF

MyDeusTools.App.exe

Standalone single-file Windows x64 executable with WPF-UI 3.0 Mica, FFmpeg CLI, PDFsharp, and GDI eyedropper.

[OPEN_GITHUB_RELEASES]

> Prerequisites & Environment

Web Client Node.js v20+ / Chrome or Edge
Windows OS (Agent / WPF) Windows 10 (1809+) / Windows 11 x64
Build From Source .NET 8.0 SDK (8.0.300+)
Agent Port 127.0.0.1:41950 (Loopback Only)

> Verify Test Suite & Hash

$ npm run web:build && dotnet test
PS> Get-FileHash .\MyDeusTools.App.exe -Algorithm SHA256

Compare hashes against official GitHub Release notes, or compile standalone EXE directly via dotnet publish.

> Complete Build & Publish Reference

git clone https://github.com/KaitoDeus/MyDeusTools.git && cd MyDeusTools
dotnet publish MyDeusTools.App/MyDeusTools.App.csproj -c Release -r win-x64 --self-contained true -p:PublishSingleFile=true -p:EnableCompressionInSingleFile=true
