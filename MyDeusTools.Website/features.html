01 // ./sticky-notes [INDEXEDDB + PiP]

Sticky Notes

Fast note capture stored automatically inside Dexie IndexedDB (MyDeusToolsWebDB.notes) on Web, or borderless topmost StickyNoteWindow overlays in WPF Desktop.

  • [WEB] Semantic accents (GREEN, AMBER, CYAN, RED), search filter, pin sorting, and Document PiP pop-out windows.
  • [WPF] Real-time auto-saving draggable desktop windows pinned above other apps + Data/notes.json persistence.

02 // ./clip-vault [CLIPBOARD_API]

Clipboard & Snippet Vault

Store reusable SQL queries, CLI commands, and tokens in IndexedDB with tags and usage counts, or capture OS clipboard history seamlessly on Windows WPF.

  • [WEB] Instant tag search, 1-click copy with USES counter, and direct OS Clipboard paste button.
  • [WPF] Event-driven Win32 AddClipboardFormatListener (WM_CLIPBOARDUPDATE) with 0% idle polling.
#DOCKER_CLEANUSES: 42
docker system prune -af --volumes
03 // ./smart-timer [2_TABS // AGENT_GATE]

Smart Timer & Scheduled Windows Shutdown

Strictly split into 2 independent tabs: browser Pomodoro countdown works offline anytime, while Windows Shutdown controls enable ONLY when Local Companion Agent is ONLINE.

  • [TAB_01:POMODORO] Screen Wake Lock API prevents display sleep, plus Web Audio chime, optional Webhook, and 70m -> 1h 10m normalization.
  • [TAB_02:SHUTDOWN] Locks every control (`disabled={!isOnline}` + `[STATUS:LOCKED]`) when offline; unlocks Shutdown, Restart, Hibernate & Cancel when Agent runs.
01:POMODORO 02:SHUTDOWN [LOCKED]
[WARN] Enable by running: npm run agent:dev
00:30:00
