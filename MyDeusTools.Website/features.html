Desktop Management

Window Pinner & Transparency

Keep critical windows always on top of your workflow. Whether you're following a YouTube video tutorial while coding in VS Code, transcribing handwritten notes, or overlaying mockups on an active browser, Window Pinner eliminates window-switching friction.

✓
Always-on-Top (HWND_TOPMOST): Pins any application window to stay above all normal and full-screen windows seamlessly.
✓
Real-time Alpha Opacity: Smoothly adjust transparency from 40% to 100% with immediate Win32 layered attribute reflection.
✓
Intelligent Window Filter: Automatically cleans out ghost background threads, tooltip handles, and Windows system overlays.
// Win32 user32.dll P/Invoke Details
SetWindowPos(
hWnd,
HWND_TOPMOST, // (-1)
0, 0, 0, 0,
SWP_NOMOVE | SWP_NOSIZE
);
SetLayeredWindowAttributes(
hWnd, 0,
(byte)(255 * opacity / 100),
LWA_ALPHA // (0x02)
);
Presets: 40% (Ghost), 70% (Tracing), 100% (Solid)

Industrial-grade mouse clicker engineered for gaming, repetitive testing, and UI automation. Unlike basic tools, it includes multi-coordinate waypoint sequences and safety throttling.

✓
Microsecond Accuracy with 10ms Safety Clamp: Enforces an automatic 10ms minimum interval clamp to guarantee Windows UI responsiveness and prevent kernel lockup.
✓
Waypoint Coordinate Recording: Record sequential screen coordinates (X, Y) across all connected monitors. Replay custom loops indefinitely.
✓
Global Hotkey (F6): Start and stop clicking immediately from inside any fullscreen application or game without alt-tabbing.

Productivity

Smart Clipboard Manager

Never lose a copied snippet again. Hooks directly into the native Windows clipboard message pump to store rich history with instant live search and persistent pinning.

✓
Zero CPU Polling: Uses Win32 AddClipboardFormatListener. The application sleeps until Windows notifies it of a clipboard change, consuming 0% idle CPU.
✓
Favorite Item Pinning: Pin frequently used code templates, email snippets, or shell commands to the top so they are never trimmed by history limits.
✓
100% Offline & Private: All entries remain stored locally in your app data folder. Zero cloud sync, zero telemetry, zero risk of data leakage.
