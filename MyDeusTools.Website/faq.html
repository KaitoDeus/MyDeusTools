// ./FAQ_AND_SECURITY

> Frequently Asked Questions

Clear answers on Web vs Local Companion Agent safety, loopback port binding, Windows SmartScreen, and privacy.

// 01. HYBRID WEB & LOCAL COMPANION AGENT

Why split Pomodoro and Scheduled Shutdown, and lock Shutdown when Agent is offline? >

Pomodoro runs 100% inside the browser (countdown + Screen Wake Lock + audio alarm) so it always works everywhere. By contrast, web browsers strictly forbid closing Windows or executing shutdown.exe. Isolating Scheduled Shutdown into Tab 2 and gating every button/input with disabled={!isOnline} prevents misleading clicks until MyDeusTools.Agent is running.

Is http://127.0.0.1:41950 exposed to my network or the Internet? >

No. LocalHttpBridgeServer binds its HttpListener prefix strictly to 127.0.0.1:41950 (loopback adapter only). External devices on LAN or the Internet cannot connect to it.

How does Auto-Clicker work inside games or desktop apps outside the browser? >

When MyDeusTools.Agent is active, Tab 2 (OS_NATIVE_AGENT) delegates mouse clicks to Win32 mouse_event and SetCursorPos (with a 10ms hardware safety clamp). GlobalHotkeyService polls VK_F6 (Start/Stop anywhere) and VK_F7 (Capture screen cursor X, Y anywhere) every 40ms via GetAsyncKeyState.

// 02. PRIVACY, DATA & SMARTSCREEN

Where are my Sticky Notes, Clipboard Snippets, and Color Palettes stored? >

In the Web app, everything (notes, snippets, colors, PDFs, images, SHA hashes) stays in your browser's local IndexedDB (MyDeusToolsWebDB) and memory — zero bytes ever upload to any external server. In Native WPF Desktop, data is stored locally under BaseDirectory\Data\*.json.

Why does Windows SmartScreen sometimes warn on standalone open-source .exe binaries? >

Unsigned open-source executables without expensive commercial EV certificates trigger standard SmartScreen reputation warnings, and Win32 APIs like mouse_event / SetWindowPos can trigger heuristic notices. You can inspect all C#/TS source on GitHub, run dotnet test (282/282), and compile binaries yourself directly.

// 03. UI, LOCALIZATION & TESTING

How do Dark/Light mode, CRT scanlines, and EN/VI language switching work? >

Every header button switches immediately with zero page reload: [THEME:DARK]/[THEME:LIGHT] toggles between #0D0D0D Phosphor Green and #F4F4EE TTY Paper, [CRT:ON]/[CRT:OFF] toggles scanlines, and [LANG:EN]/[NGÔN NGỮ:VI] switches 100% translated strings verified at build time by _viSymmetryCheck.
