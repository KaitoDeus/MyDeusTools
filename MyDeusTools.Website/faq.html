🛡️ Security, Privacy & SmartScreen

Why does Windows Defender / SmartScreen say "Windows protected your PC"?

This is a standard false positive common to all new open-source software. Microsoft SmartScreen displays this prompt for any freshly published executable that has not yet established reputation or purchased an expensive commercial Extended Validation (EV) certificate ($400+/year).

Furthermore, utilities like Auto Clicker (which programmatically emulates mouse clicks via mouse_event) and Window Pinner (which changes window TopMost flags via SetWindowPos) can trigger heuristic scanner alerts.

How to bypass: Click "More info" on the SmartScreen dialog, then click "Run anyway". You can also verify the SHA-256 hash or compile the application yourself directly from source code.

Does MyDeusTools transmit any data or telemetry?

Never. The application operates 100% offline. It contains zero analytics libraries, zero tracking pixels, and zero background network calls. All sticky notes, palette history, and settings are saved locally in your user profile folder (%AppData%\MyDeusTools).

⚙️ Features & Technical Mechanics

Why does Auto Clicker enforce a 10ms minimum interval clamp?

If an auto clicker generates hundreds of mouse clicks per millisecond with zero delay, the Windows kernel input dispatcher and graphics compositor can easily become flooded, freezing the UI and mouse pointer. The 10ms safety threshold guarantees blazing-fast click speed (up to 100 clicks/sec) while keeping the operating system responsive so you can hit F6 to stop at any time.

Does MyDeusTools support multiple monitors?

Yes, fully! Screen snipping for QR codes, pixel magnification HUD for the Color Eyedropper, and waypoint coordinate recording for Auto Clicker all work seamlessly across virtual screen bounds regardless of your multi-monitor layout or individual monitor DPI scalings.

How do I switch the application language between English and Vietnamese?

Inside the desktop app, navigate to Settings and select either English or Vietnamese. The interface updates instantaneously without requiring an application restart. All 8 tools are 100% translated.
