// ./FAQ

> Frequently Asked Questions

Quick answers on Agent gating, loopback security, SmartScreen, and privacy.

// 01. HYBRID AGENT & OS CONTROL

Why separate Pomodoro and Scheduled Shutdown, and lock Shutdown when offline? >

Pomodoro runs purely inside the browser (countdown + Wake Lock). Windows shutdown.exe requires native OS access, so Tab 2 remains disabled={!isOnline} until MyDeusTools.Agent connects.

Is http://127.0.0.1:41950 exposed to the LAN or Internet? >

No. LocalHttpBridgeServer binds strictly to loopback 127.0.0.1:41950 so external devices cannot reach it.

How does Auto-Clicker work outside the browser (F6 / F7)? >

Tab 2 invokes Win32 mouse_event / SetCursorPos via the Agent (>= 10ms clamp) with 40ms global hotkeys F6 (Start/Stop) and F7 (Capture screen X, Y).

// 02. PRIVACY & SMARTSCREEN

Where is my data stored? >

In Web, notes/snippets/colors stay in browser IndexedDB (MyDeusToolsWebDB) with zero uploads. In WPF Desktop, settings and notes live in BaseDirectory\Data\*.json.

Why does Windows SmartScreen warn on standalone .exe builds? >

Unsigned open-source executables invoking Win32 APIs (mouse_event, SetWindowPos) trigger standard SmartScreen reputation alerts. Full MIT source is inspectable and verifiable via dotnet test (282/282).

// 03. UI, I18N & TESTING

How do Light/Dark, CRT, and EN/VI switching work? >

All header switches apply instantaneously without reload and persist in localStorage; TypeScript _viSymmetryCheck enforces 100% VI/EN key parity at build time.

How is the codebase verified? >

Open-sourced under MIT by KaitoDeus & Claude, verified continuously via 282 xUnit tests and Vite + TypeScript production builds.
